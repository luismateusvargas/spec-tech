# Coding guide index

Open the common guide and the guides for languages in the files you will change. These are practical defaults, not a replacement for project configuration or local conventions.

| Files or work | Guide |
| --- | --- |
| All code changes | [Common](common.md) |
| `.py` | [Python](python.md) |
| `.js`, `.mjs`, `.cjs`; Node.js runtime code | [Node.js](nodejs.md) |
| `.ts`, `.tsx`, `.mts`, `.cts` | [TypeScript](typescript.md), plus [Node.js](nodejs.md) for Node.js runtime code |
| `.go` | [Go](go.md) |
| `.cs` | [C#](csharp.md) |
| `.cpp`, `.cc`, `.cxx`, `.hpp`, `.hh`, `.h` in C++ code | [C++](cpp.md) |
| `.rs` | [Rust](rust.md) |
| `.sh`, `.bash`, shell scripts | [Shell](shell.md) |

For a repository with its own style guide, formatter, linter, or supported version, use those settings first. Do not apply a guide to unrelated files.
